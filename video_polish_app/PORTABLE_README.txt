VIDEO POLISH — LOCAL NATIVE — WINDOWS x64 PROTOTYPE

Extract the ENTIRE ZIP to a writable folder. Double-click VideoPolish.exe.
Keep _internal beside the executable. No Python installation, GPU driver changes,
model downloads or internet connection are required for processing.

Choose Video -> Preview -> Enhance / Save MP4 -> Result.
Export: 1920x1920 with aspect-preserving padding, original constant FPS and audio.
Use a NEW output filename. Original files are never overwritten.
Processing uses CPU and may take minutes. Preview is silent, sampled up to 5 FPS.
Supports SDR constant-frame-rate square-pixel videos, no rotated metadata.
HDR/VFR are rejected. Tested on Windows 11 x64 with the original Unity MP4.
Other computers have not yet been independently tested.

This is an unsigned prototype. Windows may show an unrecognized-app notice.
Verify the sender and package hash; do not disable antivirus protections.
Third-party notices and source locations are in THIRD_PARTY.md and LICENSES.
